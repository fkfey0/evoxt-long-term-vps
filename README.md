## 长期稳定跑，Evoxt 对得上哪些指标、哪些没写

“长期稳定”这四个字拆开看是四件事：机房和线路稳不稳、会不会被超售拖死、第二年续费会不会翻倍、出问题能不能找到人。逐项对照 Evoxt 的公开页面，有的写得很清楚，有的完全空白。

**机房与线路。** 定价页只列了国家与城市，没有写机房名称、上游运营商、回程路由，也没有任何“中国优化”“CN2”“CMIN2”之类的标注。对国内访问延迟敏感的读者，这里没有可依据的信息。能确定的只是地区覆盖广，把业务放在欧洲或美洲本地时选择空间大。

**计费与续费。** 定价页展示的就是月付标价，页面上没有“首年特价”的标注，也没有单独列续费价。这种结构降低了第二年价格翻倍的风险，但页面同样没有写出“续费同价”的承诺，最终以结账页显示的循环价格为准。官方 FAQ 明确支持从月付到 3 年的预付周期，也可以先充值账户余额，让系统自动抵扣后续账单，适合不想每月手动付款的人。

## 按场景选档：三条门槛，以及什么时候别加资源

扩容单价摆在那里，很容易算出一笔糊涂账。加 1GB 内存每月 $2、加 1 个核每月 $3，听起来便宜，但大多数情况下直接跳档更划算。

**从 VM-0.75 到 VM-1。** VM-0.75 是 1 核 1GB / 10GB / 750GB，$4.99。给它加 1GB 内存变成 $6.99，硬盘还是 10GB。VM-1 是 1 核 2GB / 20GB / 1000GB，$5.99，比加内存便宜 1 美元，硬盘和流量还翻倍。想扩内存，先看上一档。

**从 VM-1 到 VM-1.5。** 这是整张表里性价比最高的一步：多 $0.96，CPU 从 1 核变 2 核，流量从 1000GB 涨到 1500GB。如果单独加 1 个 vCPU 要 $3，跳档只花三分之一。跑编译、多进程抓取、Docker 里同时开几个服务的，直接从 VM-1.5 起步。

**从 VM-2 到 VM-3。** 多 $3，CPU 从 2 核变 4 核，流量多 1TB。单独加 2 个核要 $6，跳档省一半。

**什么时候才用扩容。** 只有两种情况：你已经在 VM-16 顶部，没有更高档可跳；或者你只缺一项资源，比如硬盘够、CPU 够，就是想多 1TB 流量。这时候 $3/TB 的加购才是对的。

具体到用途：

- 代理节点、监控探针、单页静态站：VM-0.5，$2.99。512MB 内存装 Debian 加 nginx 没问题，装 MySQL 会吃紧。
- 一个 WordPress 或 Typecho 加数据库：VM-1，$5.99。2GB 内存是跑数据库的分水岭，1GB 会频繁触发 OOM。
- 多站点、容器化部署、需要本地编译：VM-1.5，$6.95。
- 中型业务、同时跑五六个服务、CI 构建：VM-2 或 VM-3，$11.99 到 $14.99。
- 高流量中转：注意月流量额度，Standard 区超了按 $3/TB 补，香港和大阪按 $12/TB 补。做流量型业务优先选 Standard 区。
- 需要 8 核以上：VM-6 起，$29.99。到这个量级，月付三年 $1,079.64，值得先确认是否真需要独占资源。

## 哪些人不必买 Evoxt

**需要中国方向低延迟的。** 官方页面没有任何优化线路标注，香港和大阪虽然地理近，但流量只有 Standard 区的一半，超流量单价还是四倍。如果你的核心诉求是国内访问快，应该去找明确标注 CN2 GIA、CMIN2、AS9929 这类回程线路的商家，第三方测评里 DMIT 走的就是这个方向，年付价位在 $36.9 起（测评页面口径），属于另一个价格区间。

**只想一次付一年、越便宜越好的。** 这类需求在年付促销机里选择很多。第三方测评页面显示，RackNerd 的年付套餐 1 核 1GB / 24GB / 2TB 做到 $11.29/年，1 核 2GB / 40GB / 3.5TB 是 $18.29/年，机房在美国多地，支持支付宝。ZGoVPS 的德国 Falkenstein 节点年付 $12.90 起（1 核 1GB / 20GB NVMe / 2TB），配置用 Xeon Gold 5412U 加 DDR5，但官方写明是国际线路、不对中国优化，也不支持以国内速度慢为由退款，入门档还经常缺货。这两家的年支出都远低于 Evoxt 的最低档。

**需要按小时试错的。** Evoxt 最短计费周期是月付，没有按小时计费。想先跑几小时看看线路和性能再决定长期方案，按小时计费的商家更合适。

**需要支付宝付款的。** 前面提过，官方 FAQ 里没有这个选项。

反过来说，Evoxt 适合的是这类人：业务量还在变，需要随时把 1 核升到 4 核；或者站点分布在不同地区，想在同一家开美国、德国、日本三台机器统一管理；或者单纯不想为了一台机器一次押上一年。

**操作系统。** 可选范围从 Windows RDP 到各类 Linux 发行版。

**续费价。** 结账页显示的循环价格才是你要付的，页面上没有首期折扣，也没有续费同价承诺的文字。
